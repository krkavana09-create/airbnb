# 🏠 Airbnb Price Prediction

A machine learning web application that predicts Airbnb listing prices based on property details and other relevant features. The application uses a trained regression model and provides an interactive interface built with Streamlit.

## 🚀 Live Demo

**Try the application here:** [Airbnb Price Prediction]https://airbnb-mwsg4fyn4txhggy7kukmdm.streamlit.app/

## 📌 Project Overview

The objective of this project is to estimate the price of an Airbnb listing using machine learning. Users can enter property details through a web interface and receive a predicted price.

## ✨ Features

- Predict Airbnb listing prices using a trained machine learning model.
- Interactive web interface built with Streamlit.
- Data preprocessing and feature transformation.
- Real-time predictions based on user inputs.
- Online deployment through Streamlit Community Cloud.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/krkavana09-create/airbnb.git
   ```

2. Navigate to the project directory:

   ```bash
   cd airbnb
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit application:

   ```bash
   streamlit run app1.py
   ```

## 🧠 Machine Learning

The application loads a previously trained regression model using Joblib to generate predictions. The model and preprocessing steps should use compatible versions of their required libraries.
